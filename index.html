图表类型使用指南

流程图

流程图是展示业务流程和工作流程的最佳工具。通过标准化符号和清晰箭头，帮助您可视化决策路径、业务逻辑和操作步骤。适用于项目管理、流程优化和系统设计。

时序图

时序图用于展示系统组件之间的交互时序和消息传递。非常适合描述API调用、函数调用链和分布式系统中的请求响应流程。是软件架构设计的重要工具。

类图

类图是面向对象编程的核心工具，展示类的属性、方法和类之间的关系。帮助开发团队理解系统结构，实现代码生成和逆向工程。适用于软件设计和架构文档。

状态图

状态图描述对象在其生命周期内所经历的状态序列以及导致状态转换的事件。适用于游戏开发、工作流引擎和协议设计等领域。

甘特图

甘特图是项目管理的经典工具，通过条形图展示项目进度、任务依赖和时间安排。帮助项目经理追踪进度、协调资源和优化工作流程。

思维导图

思维导图是一种放射性思维的表达方式，适合头脑风暴、笔记整理和知识管理。通过中心主题向四周发散，帮助您组织想法和激发创意。

ER图

ER图(实体关系图)是数据库设计的标准工具，展示实体、属性和实体之间的关系。帮助设计师规划数据库结构，是系统分析和数据库开发的重要文档。

Git图

Git图可视化展示代码版本历史和分支合并情况。帮助开发团队理解代码演进、追踪bug引入点和管理多人协作开发。是现代软件开发不可或缺的工具。

用户旅程

用户旅程图展示用户在产品或服务中的完整体验过程。通过阶段划分和情感评分，帮助产品团队识别用户痛点和优化机会。

饼图

饼图是最直观的数据可视化工具之一，通过圆形切片展示各部分占比情况。适合展示市场份额、预算分配、调查结果等比例数据。

时间线

时间线图用于展示事件发展的时间顺序和历史进程。适合公司发展历程、项目里程碑、个人履历等场景。

看板

看板是一种可视化的工作流程管理工具，通过列式布局展示任务在不同阶段的状态。帮助团队实现可视化协作。

四象限

四象限图通过二维矩阵将项目或任务按重要性和紧急性进行分类。帮助用户识别优先级，做出合理的资源分配决策。

桑基图

桑基图是一种高效的流向可视化图表，宽度代表流量大小。适用于能源分配、资金流动、用户转化等场景。

XY图表

XY图表结合柱状图和折线图，展示数据的变化趋势和对比。支持双轴显示，是数据分析报告的常用图表类型。

块状图

块状图用于展示系统架构和模块之间的关系。通过方块和连线展示系统的组成部分和数据流向。

架构图

架构图是系统设计的核心工具，展示系统的技术栈、组件交互和部署结构。是技术方案评审和文档编写的重要依据。

数据包图

数据包图用于可视化网络协议和数据结构。展示数据包各字段的含义和层次关系，是网络教学和协议分析的有效工具。

Mermaid 语法速查表

流程图

A[矩形] 普通节点
A(圆角) 开始/结束
A{菱形} 判断节点
A-->B 箭头连接
A-->|文本|B 带标签箭头

时序图

participant A 定义参与者
A->>B: 消息 同步消息
A-->>B: 消息 异步消息
A-->B 返回消息
Note over A,B 注释

类图

class A 定义类
+属性 公开属性
-属性 私有属性
A <|-- B 继承关系
A *-- B 组合关系

状态图

[*] --> A 初始状态
A --> B 状态转换
A --> B: 事件 带事件转换
B --> [*] 结束状态

甘特图

title 标题 图表标题
dateFormat YYYY-MM-DD 日期格式
section 阶段 分组阶段
任务: id, 5d 任务(天数)

思维导图

root((中心)) 中心主题
分支 一级分支(2空格)
子分支 二级分支(4空格)

ER图

A ||--o{ B 一对多
A {|--|{ B 一对一
A { 实体开始
int id PK 主键

饼图

pie title 标题 饼图标题
"标签" : 数值 数据项
